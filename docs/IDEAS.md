# Idea Repository

## Account Protection
- [] Add a feature for scheduled backup sessions that would randomly start backups during the first hour of the backup to avoid potentially flagging the account for ripping.
    - The logic goes as follows: theoretically, a human is highly unlikely to start listening to a track at a specific time either every day or every week. Therefore, it would be ideal if the backups had random start times during the window within which they're set to start backing up tracks. This could be a feature enabled by default in the settings of the webUI
